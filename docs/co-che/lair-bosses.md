## Paladin Bossing Checklist

1. Có single-target variant hoặc skill gây damage chính ổn.
2. Có defensive để sống qua burst/telegraph.
3. Không dùng full speed-farm setup nếu boss là mục tiêu chính.
4. Loot Filter có rule `Is Specific Unique` nếu săn item cụ thể.
5. Ghi boss, difficulty, số run và drop đáng chú ý.

## Khi Build AoE Nhưng Boss Yếu

| Cách sửa | Đổi ít nhất có thể |
|---|---|
| Thêm bossing Charm | Giữ gear/skill chính, đổi 1-2 Charm. |
| Đổi skill variant single-target | Giữ Oath và Paragon nếu vẫn scale cùng tag. |
| Đổi Talisman set | Chỉ đổi khi set bossing rõ ràng hơn. |
| Hạ difficulty | Nếu boss chết quá chậm, lower tier có thể hiệu quả hơn. |

## Test Pass/Fail

| Test | Pass | Fail |
|---|---|---|
| Target boss route | Boss chết nhanh, drop pool đúng, key sustain ổn | Hết key/material hoặc boss quá chậm |
| Bossing mode | Kill time giảm mà không chết nhiều | Damage tăng nhưng mất defense quá lớn |
| Loot Filter Unique | Không bỏ sót item mục tiêu | Filter ẩn nhầm đồ tốt hoặc quá nhiều noise |
