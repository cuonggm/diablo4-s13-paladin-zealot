## Dùng Helltide Khi Nào

| Mục tiêu | Lý do |
|---|---|
| Leveling nhanh | Nhiều quái, nhiều objective, dễ giữ nhịp combat. |
| Gear nền | Nhiều drop để thay weapon/shield/armor. |
| Test pack clear | Quái đông giúp kiểm AoE, resource và sustain. |
| Farm song song Whispers | Nếu vùng/objective overlap, hiệu quả cao hơn. |

## Paladin Cần Chú Ý

| Vấn đề | Cách xử lý |
|---|---|
| Bị bao vây | Giữ defensive cooldown, Unstoppable hoặc mobility để thoát. |
| Pack tản | Dùng skill gom/cleave/AoE hoặc route quanh event đông quái. |
| Faith cạn | Giảm spam spender, thêm generator/resource support. |
| Chết vì ground effect | Giảm Map Overlay opacity hoặc tắt overlay khi combat. |
| Boss/elite chậm | Đổi một skill/Charm sang single-target trước khi tăng difficulty. |

## Route Gợi Ý

1. Chọn Helltide trong War Plan nếu mục tiêu là gear/density.
2. Ưu tiên objective đang overlap Whispers.
3. Dọn pack đông, elite và event thay vì chạy quá xa.
4. Mở chest/reward theo mục tiêu, không nhặt mọi món nếu filter đã bật.
5. Sau 15-30 phút, ghi: death, potion, Faith, pack clear, drop đáng giữ.

## Test Pass/Fail

| Test | Pass | Fail |
|---|---|---|
| Helltide cùng difficulty | Pack chết nhanh, ít potion, túi có upgrade/material | Elite kéo dài, death tăng, phải kite liên tục |
| Tăng difficulty | Reward/hour tăng hoặc không giảm | Time-to-kill tăng quá nhiều |
| Dùng Helltide để test AoE | Thấy rõ skill nào clear pack tốt | Kết quả nhiễu vì route/event quá khác nhau |
