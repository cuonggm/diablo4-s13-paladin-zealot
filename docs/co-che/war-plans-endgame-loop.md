## Tạo War Plan Theo Mục Tiêu

| Mục tiêu | Activity nên chọn | Vì sao |
|---|---|---|
| XP và density | Helltide, Infernal Hordes, Nightmare Dungeon | Nhiều quái, dễ test clear pack. |
| Gear nền | Helltide, Whispers chồng activity, War Chest | Nhiều drop/cache. |
| Unique/boss item | Lair Bosses, boss key reward, target farming | Tập trung loot pool. |
| Material/Cube | War Chest, Undercity, Whispers, elite-heavy activity | Cube cần material từ nhiều nguồn. |
| Glyph/Paragon/push | Pit, Nightmare Dungeon tùy reward patch | Đo sức mạnh và nâng power dài hạn. |
| Test build | Một plan ngắn, activity quen thuộc | Dễ so sánh trước/sau đổi build. |

## Template War Plan Cho Paladin

| Template | Dùng khi | Gợi ý |
|---|---|---|
| `Pilgrim Farm` | Level 70 sớm, cần gear/material | Helltide -> Whispers overlap -> NMD/Pit thấp -> War Chest. |
| `Forge Run` | Cần Cube/Tempering/Masterworking | Activity nhiều elite + Whispers + Undercity/War Chest. |
| `Oath Trial` | Test Oath/skill variant | Chọn activity quen, không quá dài, có cả pack và elite. |
| `Boss Rite` | Thiếu Unique/key item | Lair Bosses + activity cho boss key/material. |
| `Bulwark Push` | Test defense/push | Pit/NMD khó hơn một bậc, giữ rollback difficulty. |

## Cách Không Bị Farm Lan Man

1. Trước khi tạo War Plan, ghi mục tiêu: XP, gear, material, boss key, Glyph, push hay test.
2. Chọn activity phục vụ mục tiêu đó, không chọn vì "đang gần".
3. Tắt hoặc chỉnh Loot Filter trước khi vào plan nếu mục tiêu là gear.
4. Sau khi hoàn tất War Chest, dọn túi và ghi vấn đề mới.
5. Nếu plan mất nhịp hoặc quá khó, hạ difficulty ở plan kế tiếp thay vì cố sửa giữa run.
