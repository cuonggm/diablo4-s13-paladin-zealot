## Dùng Command Table Để Làm Gì

| Việc | Ý nghĩa thực tế |
|---|---|
| Tạo War Plan | Chọn chuỗi activity và reward trước khi farm. |
| Xem progression | Theo dõi level Command Table và activity tree đã mở. |
| Định hướng session | Biến "chạy gì cũng được" thành một route có mục tiêu. |
| Quay về Temis | Patch 3.0.2 cho phép teleport tới active War Plan hoặc Temis nếu không có plan active. |

## Checklist Trước Khi Bấm Start

1. Túi còn trống đủ cho cả plan.
2. Loot Filter đang dùng đúng mục tiêu hiện tại.
3. Difficulty không vượt quá khả năng sống sót của Paladin.
4. Skill bar có đủ mobility, defensive và resource loop.
5. Đã biết activity nào trong plan là điểm test chính.

## Ưu Tiên Cho Paladin

| Tình trạng nhân vật | Command Table nên phục vụ |
|---|---|
| Level 70 mới vào endgame | Plan ngắn, Helltide/NMD dễ, reward gear/material. |
| Thiếu Faith hoặc cooldown lệch | Activity quen để test rotation, không chọn push ngay. |
| Thiếu Unique | Plan có Lair Bosses hoặc reward liên quan boss key. |
| Đang min-max Talisman/Cube | Plan có War Chest, Undercity, Whispers và elite-heavy activity. |
| Chơi Hardcore | Tránh lock plan quá khó; hạ difficulty trước khi chạy chuỗi dài. |
