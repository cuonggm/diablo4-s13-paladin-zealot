| Kết luận | Status | Impact on Paladin |
|---|---|---|

## Cách Chọn Paragon/Glyph

| Câu hỏi | Ý nghĩa |
|---|---|
| Damage chính là skill nào? | Board/glyph phải scale engine thật, không scale skill phụ. |
| Damage type là gì? | Holy/Physical/DoT/crit/Overpower khác nhau. |
| Skill tag sau variant là gì? | Bonus Skill Variant có thể đổi tag, làm guide cũ sai. |
| Build thiếu gì? | Paragon có thể sửa defense/resource, không chỉ damage. |
| Activity mục tiêu là gì? | Speed farm, bossing, push, Hardcore cần path khác nhau. |

## Recommend Cho Paladin

| Hướng | Paragon/Glyph ưu tiên |
|---|---|
| Zealot Zenith | Crit, attack speed, Core/Ultimate, Zealot/Fervor synergy, defense nền. |
| Shield/Juggernaut | Block, armor, resist, DR, Life, Resolve/Juggernaut synergy. |
| Judicator bossing | Core Judicator, single-target, debuff/mark, boss damage, resource stability. |
| Disciple/Arbiter | Cooldown/window, Holy/Disciple skill, movement/defense ngoài window. |
| Hardcore | Lấy defense breakpoint trước khi tối ưu damage node xa. |

## Không Respec Sâu Khi Nào

| Tình huống | Lý do |
|---|---|
| Chưa chốt Core Skill | Board theo skill cũ có thể vô nghĩa. |
| Chưa có Unique/Aspect bắt buộc | Planner endgame có thể không hoạt động. |
| Vừa tăng difficulty và chết nhiều | Sửa defense/gear trước, đừng nghĩ Paragon là lỗi duy nhất. |
| Đang test một flex skill | Chỉ đổi skill slot; đừng đổi cả board. |

## Mini Checklist Sau Level 70

1. Chốt damage engine hiện tại.
2. Chọn Glyph scale đúng engine.
3. Lấy rare/magic node giúp defense nếu vào Torment bị đau.
4. Nâng Glyph bằng activity phù hợp theo patch hiện tại.
5. Ghi lại board/glyph chính trong [Nhật Ký Test](../../notes/nhat-ky-test.md) trước khi respec lớn.
