## Khi Nào Chạy Tower

| Nên chạy khi | Không nên chạy khi |
|---|---|
| Build đã mượt trong Pit/NMD cùng tier. | Đang thiếu defense nền. |
| Muốn đo score/leaderboard. | Đang cần farm material gấp. |
| Muốn reward milestone/GA item. | Chưa ổn rotation hoặc resource loop. |
| Muốn học build top qua Build Viewer. | Định copy meta mà thiếu item/key mechanic. |

## Paladin Checklist

1. Có mode rõ: speed clear, boss burst hay tank push.
2. Defense đủ để quái Tower không ép uống potion liên tục.
3. Mobility không làm lệch rotation.
4. Talisman/Charm có rollback nếu đổi sang setup score.
5. Sau run, ghi score, tier, death, bottleneck và reward.

## Cách Dùng Build Viewer

| Việc | Ghi chú |
|---|---|
| Xem top build | Dùng để tham khảo skill/gear/Paragon/Talisman. |
| So với nhân vật mình | Kiểm required item, GA, Masterwork, Seal/Charm trước. |
| Không copy mù | Build leaderboard có thể tối ưu score, không tối ưu farm/hardcore. |
| Lấy ý tưởng nhỏ | Ưu tiên học 1-2 slot flex hoặc Talisman logic. |
