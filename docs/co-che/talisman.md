## Kết Luận Nhanh

| Kết luận | Status | Impact on Paladin |
|---|---|---|
| Talisman là hệ item mới dùng Seal và Charm để thêm affix, power và set bonus. | Verified | Xem như một lớp build riêng bên cạnh gear, Aspect, Paragon. |
| Seal mở Charm slots; Charm đặt vào slot để thêm bonus. | Verified | Seal tốt là nền, Charm tốt là phần tinh chỉnh. |
| Set Charms tạo partial/full set bonus, có set class-specific và all-class. | Verified | Paladin nên chọn set theo Oath/skill engine, không theo rarity thuần. |
| Patch 3.0.2 làm Set Charms dễ nhận biết hơn qua Unique drop sound và minimap icon. | Verified | Ít bỏ sót charm quan trọng khi farm nhanh. |

## Cách Nghĩ Về Talisman

| Lớp | Vai trò |
|---|---|
| Seal | Khung chính: số slot, affix nền, độ linh hoạt. |
| Charm | Mảnh bonus: affix, set, Unique power. |
| Set bonus | Điều kiện để biến Talisman thành engine build. |
| Loot Filter | Cách không bỏ sót đúng Seal/Charm giữa lượng drop lớn. |

## Ưu Tiên Cho Zealot Zenith

| Nhu cầu | Talisman nên hỗ trợ |
|---|---|

## Quy Trình Đổi Talisman

1. Ghi setup đang dùng: Seal, số slot, set, charm chính.
2. Chỉ đổi 1-2 mảnh một lần.
3. Test cùng activity và cùng difficulty trong 15-30 phút.
4. Ghi vấn đề: damage pack, boss damage, sống sót, Faith, cooldown.
5. Nếu tệ hơn, rollback setup cũ thay vì tiếp tục đổi nhiều thứ.
